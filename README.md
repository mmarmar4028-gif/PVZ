# Защита ПВЗ

Сайт-прототип сервиса для владельцев пунктов выдачи заказов. Учебный проект команды №4 для Ингосстраха.

**Сайт:** https://mmarmar4028-gif.github.io/pvz/

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: услуги, тарифы с расчётом по числу точек, подбор тарифа, FAQ, чат-бот |
| `apply.html` | Заявка на подключение: тариф, точки, контакты, проверка полей |
| `account.html` | Личный кабинет: обзор и лимиты, споры, срочная помощь (замена сотрудника), финансы, юридическое, шаблоны, FAQ, чат с куратором, профиль |
| `tools.html` | Бесплатные инструменты: претензия по удержанию, прибыль точки, порог НДС |

Общий код лежит в `assets/`: `style.css` (дизайн), `app.js` (тарифы, FAQ, чат-бот, шапка), `tools.js` (калькуляторы и претензия), `account.js` (кабинет).

## Демо-режим

У сайта нет сервера. Заявка и данные кабинета хранятся в `localStorage` браузера и никуда не отправляются. Чат-бот отвечает по встроенной базе вопросов.

## Как изменить тарифы или FAQ

Массивы `TARIFFS` и `FAQ` в начале `assets/app.js`.

## Публикация

Settings → Pages → Source: Deploy from a branch, Branch: `main`, папка `/ (root)`.
